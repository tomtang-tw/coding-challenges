## Detailed Category Feedback

### Core Logic Analysis

The rotation algorithm in `TeamRotator.kt` is a textbook index-based round-robin:

```kotlin
fun rotate(): Member {
    throwErrorIfAllMemberInactive()
    rotateLastSelectedIndex()
    while (!membersList[lastSelectedIndex].isActive()){
        rotateLastSelectedIndex()
    }
    return membersList[lastSelectedIndex]
}

private fun rotateLastSelectedIndex() {
    lastSelectedIndex++
    if (lastSelectedIndex >= membersList.size) lastSelectedIndex = 0
}
```

**How it avoids immediate repetition:** The `lastSelectedIndex` always increments by at least 1 before the while loop, so with 2+ active members, the cursor will always land on a different member. For single active member, the cursor wraps all the way around — correctly allowing repetition.

**Inactive member handling:** The `while` loop skips inactive members by continuing to advance. The `throwErrorIfAllMemberInactive()` pre-check prevents an infinite loop by checking for any active member first.

**Batch rotation (`rotateNMembers`):** Simply calls `rotate()` in a loop and collects results. Simple, correct, and leverages the single-rotation logic.

The only subtlety worth noting: deactivating a member doesn't reset `lastSelectedIndex`, so the rotation cursor position is preserved across status changes. This is correct behavior.

### Code Quality Analysis

The code is clean and functional but lacks architectural depth. The `TeamRotator` class is a monolithic service that handles both rotation logic and member management. In a more formal design:

- An `ITeamRotator` interface would define the contract
- A `MemberRepository` could handle member CRUD
- The rotation strategy could be pluggable

The 4 custom exception classes are a highlight — they show professional error handling design. The `StringExtensions.kt` with `equalsIgnoreCase` demonstrates Kotlin idiom awareness.

The `data class Member` with mutable `var isActive` is a design tension. In Kotlin, `data class` typically represents immutable value objects. Having mutable state in a `data class` means `copy()` and destructuring may produce unexpected results.

### 💡 Suggestion 5: Replace `data class Member` with Regular Class

**Current Implementation:**
```kotlin
data class Member(val fullName: String, private var isActive: Boolean = true) {
    fun deactivate() { isActive = false; }
    fun activate() { isActive = true }
    fun isActive(): Boolean { return isActive }
}
```

**Issue:**
`data class` in Kotlin generates `equals()`, `hashCode()`, `copy()`, `toString()`, and destructuring based on constructor parameters. With `private var isActive`, the generated methods only use `fullName` — meaning two members with the same name but different active status are considered "equal." This works for tests but is semantically confusing. `data class` implies immutable value objects; this has mutable state.

**Recommended Approach:**
```kotlin
class Member(val fullName: String, isActive: Boolean = true) {
    var isActive: Boolean = isActive
        private set  // Readable externally, writable only internally

    fun deactivate() { isActive = false }
    fun activate() { isActive = true }

    override fun equals(other: Any?): Boolean =
        other is Member && fullName == other.fullName

    override fun hashCode(): Int = fullName.hashCode()
    override fun toString(): String = "Member(fullName=$fullName, isActive=$isActive)"
}
```

**Impact:** Clearer semantic intent. Explicit `equals`/`hashCode` based on `fullName` is intentional rather than accidental. Includes `isActive` in `toString()` for debugging.

**Recommended Approach:**

```markdown
### Algorithm: Index-Based Round-Robin

The `TeamRotator` uses a simple index-based round-robin algorithm:
1. Maintain a `lastSelectedIndex` starting at -1
2. On each `rotate()` call, increment the index (wrapping to 0 at list end)
3. Skip inactive members by continuing to increment
4. Pre-check for any active member to prevent infinite loops

**Time Complexity:** O(n) per rotation (worst case: all but one inactive)
```

```kotlin
package org.example

class TeamRotator {

    val membersList: List<Member>
    private var lastSelectedIndex: Int = -1;

    constructor(membersList: List<Member>) {
        if (membersList.isEmpty()) throw ListOfMemberCannotBeEmptyException()
        ensureNameNotDuplicate(membersList.map{ it.fullName }.toList())
        this.membersList = membersList
    }

    constructor(vararg memberNameList: String): this(memberNameList.map { Member(it) })

    private fun ensureNameNotDuplicate(memberNameList: List<String>) {
        val seen = mutableSetOf<String>()
        for (name in memberNameList) {
            if (!seen.add(name)) {
                throw ListContainDuplicatedNameException(name)
            }
        }
    }

    fun memberList(): List<Member> {
        return membersList;
    }

    fun rotate(): Member {
        throwErrorIfAllMemberInactive()
        rotateLastSelectedIndex()
        while (!membersList[lastSelectedIndex].isActive()){
            rotateLastSelectedIndex()
        }
        return membersList[lastSelectedIndex]
    }

    private fun throwErrorIfAllMemberInactive() {
        val firstOrNull: Member? = membersList.firstOrNull { it.isActive() }
        if(firstOrNull == null) throw NoActiveMembersAvailable();
    }

    private fun rotateLastSelectedIndex() {
        lastSelectedIndex++
        if (lastSelectedIndex >= membersList.size) lastSelectedIndex = 0
    }

    fun lastSelectedMember(): Member {
        return membersList[lastSelectedIndex];
    }

    fun rotateNMembers(n: Int): List<Member> {
        val result = mutableListOf<Member>();
        for (i in 1..n) {
            val member = rotate();
            result.add(member);
        }
        return result;
    }

    fun markMemberInactiveByName(memberName: String) {
        val member = findMemberByNameIgnoreCaseOrNull(memberName) ?: throw MemberNotFoundException(memberName)
        member.deactivate()
    }

    fun isMemberActive(memberName: String): Boolean {
        val member = findMemberByNameIgnoreCaseOrNull(memberName) ?: throw MemberNotFoundException(memberName)
        return member.isActive()
    }

    fun markMemberActiveByName(memberName: String) {
        val member = findMemberByNameIgnoreCaseOrNull(memberName) ?: throw MemberNotFoundException(memberName)
        member.activate()
    }

    private fun findMemberByNameIgnoreCaseOrNull(memberName: String): Member? {
        val member = membersList.firstOrNull { it.fullName.equalsIgnoreCase(memberName) }
        return member
    }
}
```
